# 05 — API Reference

Base URL (dev): `http://localhost:8000`. Interactive docs at `/docs` (Swagger,
auto-generated by FastAPI).

## Phase 0

### `GET /health`
Liveness check.
```json
{ "status": "ok", "service": "noacf-api", "version": "0.1.0" }
```

## Planned (grown per phase)

| Phase | Endpoint | Purpose |
|---|---|---|
| 1 | `POST /auth/signup`, `POST /auth/login`, `POST /auth/logout`, `GET /me` | Supabase Auth wrapper + profile |
| 2 | `POST /import/letterboxd` (multipart CSV) | Parse export, match TMDB, upsert `films`/`user_films` |
| 2 | `GET /films/search?q=` | TMDB search proxy |
| 2 | `GET /films/mine`, `POST /films/mine`, `PATCH /films/mine/{id}` | Library management |
| 3 | `POST /conversations`, `GET /conversations/{id}`, `POST /conversations/{id}/messages` | Reflection/discovery chat |
| 4 | `POST /conversations/{id}/end` → proposed memories; `PATCH /memories/{id}` (confirm/edit/reject) | Guided review |
| 5 | `GET /memories?status=`, `GET /profile/summary` | Reflective profile views |
| 6 | `POST /recommendations`, `POST /recommendations/{id}/feedback` | Reflection-informed recs + feedback loop |

## Conventions
- Auth: `Authorization: Bearer <supabase access token>`; server verifies JWT.
- Errors: RFC 7807-style `{ "detail": "..." }` with appropriate status codes.
- All list endpoints paginated (`limit`/`offset`); chat context assembly is
  server-side and never exposed raw.
